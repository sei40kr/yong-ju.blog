QBism (量子ベイズ主義, Quantum Bayesianism) は量子力学の解釈の1つ。
**量子状態は世界の側にある性質ではなく、それを使うagentが測定結果に賭ける信念の度合い**、と読む。

- 量子状態 $\rho$ は「この測定をしたらこの結果がこの確率で出る」という、agent個人の確率の割り当てをまとめたもの
- 測定結果は、agentが世界に働きかけて得る個人的な経験。測定前から世界のどこかに書いてあった値を読み出すものではない
- Born則は「正しい確率を計算する自然法則」ではなく、**行わない測定への確率と行う測定への確率を整合させる規範**。確率論のBayes的な整合性条件に、量子力学が1つ付け加えたもの

売りは、量子状態を信念と読むだけで測定問題と非局所性が消えること。
代わりに「それでは物理学が世界について何も言っていないのでは」という批判を常に受けている。

## コンセプト

### 確率は信念である

QBismの出発点は量子論ではなく確率論の側。
**主観確率** (subjective probability) の立場では、確率は世界の中にある量ではなく、agentが賭けにどこまで応じるかという信念の度合い。
「このコインの表が出る確率は0.5」は、コインの性質の記述ではなく「表に賭ける1円の券を50銭で買ってもよい」というその人の態度の記述。

確率に制約を与えるのは、世界との一致ではなく**整合性** (coherence)。

確率の割り当てが確率論の公理 (非負、全体で1、加法性) を破っている
→ 相手がうまく賭けを組み合わせると、どの結果が出てもこちらが損をする組み合わせ (Dutch book) が作れる
→ 公理は「従うべき規範」であって、「世界が従っている法則」ではない

QBismはこれを量子確率にそのまま持ち込む。
Born則で計算した確率も他のあらゆる確率と同じく信念の度合いで、「正しい確率」が別に世界の側にあるわけではない。

### 量子状態は信念である

古典的な確率分布 $p(x)$ がagentの情報を表すものなら、それを一括して与える量子状態 $\rho$ も同じく信念を表すもの。
QBismはここで止まらず、**「未知の量子状態」という概念を捨てる**。

状態トモグラフィーで「未知の状態を推定する」とき、実験家は同じ装置で用意した系をたくさん測って $\rho$ を当てる。
この手続きは「未知の $\rho$ を知る」ことなしに書ける (量子de Finetti定理)。

系の列について「順番を入れ替えても信念が変わらない」(交換可能性) だけを仮定する
→ その列への信念は必ず $\rho^{(n)}=\int P(\rho)\,\rho^{\otimes n}\,d\rho$ の形になる
→ データを見るたびに $P(\rho)$ をBayes更新していくのがトモグラフィー
→ 「世界が持っている真の $\rho$」を仮定する必要はどこにもない

古典のde Finetti定理が「未知の確率」を信念の更新に置き換えたのと同じ構図。

同じ系に対して2人のagentが別の $\rho$ を割り当てることも、どちらも間違っていないという意味で許される。
情報が違えば信念も違う。

### 測定は経験であり、収縮は信念の更新である

測定結果は、agentが世界に問いかけたときに新しく生じる経験。
測定前から値が決まっていて、それを読み出しているのではない。
Bell不等式の破れは「測定前から値が決まっていた」とする立場 (局所実在論) を否定するが、QBismはそもそも測定前の値を仮定しないので何も困らない。

測定後に状態が $\rho$ から $\rho'$ に変わる「収縮」も、物理的な過程ではなく**信念の更新**。
古典のBayes更新 $p(x)\to p(x|\text{データ})$ が、データを見た人の頭の中でだけ起きるのと同じ。

![「状態の収縮」は確率ベクトルの書き換え](/img/qbism-update.svg)

図は後述するSIC表示で、ある測定の結果を見る前と後の状態を4つの確率の組として並べたもの。
「収縮」はこの4つの数の書き換えでしかない。

この読み方で、量子力学の2つの古典的な難題がそのまま消える。

- **測定問題**: 収縮が物理過程でないなら、「収縮はいつ、どの物理過程で起きるのか」は問いとして成立しない。シュレディンガー方程式による発展と収縮は競合する2つの物理法則ではなく、「情報が増えない間の信念の変化」と「情報を得たときの信念の変化」
- **非局所性**: EPR状態でAliceが測定するとBobの側の状態が「瞬時に収縮する」ように見えるが、変わったのはAliceのBobに対する信念だけ。Bobの側では何も起きていない。遠隔作用はそもそも存在しない

<Hint level="info">
  「量子状態が主観的」と「世界が主観的」は別で、QBismは後者を主張しない。測定結果はagentの思い通りにならず、世界は常にagentを驚かせる。この「制御できない応答」こそが世界の実在性で、量子状態はそれに対する賭けの態度にすぎない。
</Hint>

### Wignerの友人

Wignerの友人が密室で測定をして結果を見た。
友人にとって状態は収縮しているが、密室の外のWignerにとって「友人と系」は依然として重ね合わせのまま。
コペンハーゲン解釈ではどちらが正しいかが問題になるが、QBismではどちらも正しい。
量子状態はagentごとの信念なので、Wignerと友人が別の状態を割り当てることに矛盾はない。
量子力学は、それを使う**1人のagentのための理論** (single-user theory)。

Wignerが後で友人に結果を尋ねれば、その会話はWignerにとっての測定であり、Wignerは自分の信念を更新する。
2人の信念はそこで (たいてい) 一致するが、一致は物理法則の帰結ではなく、同じ経験を共有したことの帰結。

## Born則の書き換え

QBismの技術的な核心は、Born則を「確率から確率への関係」に書き直すこと。
Hilbert空間の言葉を捨てて、すべてを確率の言葉で書く。

### SIC-POVM

$d$ 次元の系で、$d^2$ 個のrank-1の射影 $\Pi_i=|\psi_i\rangle\langle\psi_i|$ が

$$
\mathrm{Tr}(\Pi_i\Pi_j)=\dfrac{1}{d+1}\;(i\ne j),\qquad\sum_{i=1}^{d^2}\Pi_i=d\,I
$$

を満たすとき、$E_i=\Pi_i/d$ の組を **SIC-POVM** (symmetric informationally complete POVM) という。
任意の2つの要素がどれも同じ角度をなしていて (symmetric)、$d^2$ 個の結果の確率から状態 $\rho$ が一意に復元できる (informationally complete)。

$d=2$ では、4つの $\Pi_i$ のBlochベクトルがBloch球に内接する正四面体の頂点になる。

![qubitのSICはBloch球に内接する正四面体](/img/qbism-sic.svg)

<Hint level="info">
  SIC-POVMがすべての次元で存在するかは未解決
  (Zauner予想)。厳密解と数値解が多くの次元で見つかっているが、一般の証明はない。QBismの定式化はこの存在を仮定している。
</Hint>

SIC測定の結果への確率 $p(i)=\mathrm{Tr}(\rho E_i)$ から、状態は

$$
\rho=\sum_{i=1}^{d^2}\left\{(d+1)\,p(i)-\dfrac1d\right\}\Pi_i
$$

と復元できる。
つまり**量子状態とは $d^2$ 個の確率の組**であり、密度行列はそれを並べ直したものにすぎない。

- Q. $d^2$ 個の確率の組ならなんでも量子状態になるか? → A. ならない。$\rho$ が正でなければならないという制約から、確率ベクトルの集合 (確率単体) の中で量子状態になるのはごく一部

![qubitの状態空間は確率単体の内接球](/img/qbism-state-space.svg)

qubitの場合、純粋状態は $\sum_i p(i)^2=1/3$ の球面、混合状態はその内側で、確率単体 (正四面体) の内接球にちょうど一致する。
頂点 $p=e_i$ (「結果 $i$ が確実に出る」という信念) は量子状態として許されない。
SIC測定の結果は、どんな状態でも最大で $1/d$ の確率でしか予測できない。

### Urgleichung

SIC測定を「空の測定」と呼ぶ。
agentが実際に行うのは別の「地上の測定」$\{D_j\}$ で、その確率が知りたい。

まず、空の測定を実際に行ってから地上の測定を行い、空の結果は捨てる場合。
空の結果が $i$ だったときの状態を $\Pi_i$ とすると、地上の結果 $j$ の確率はただの全確率の法則で

$$
\sum_i p(i)\,r(j|i),\qquad r(j|i)=\mathrm{Tr}(\Pi_iD_j)
$$

になる。

次に、空の測定を行わず、直接地上の測定を行う場合。
Born則 $q(j)=\mathrm{Tr}(\rho D_j)$ に先ほどの $\rho$ の復元式を代入すると

$$
q(j)=(d+1)\sum_i p(i)\,r(j|i)-1
$$

が得られる。
これを **Urgleichung** (ドイツ語で「原方程式」) と呼ぶ。
全確率の法則との違いは、係数 $d+1$ と定数 $-1$ だけ。

![空の測定を実際に行うかどうかで、地上の確率は変わる](/img/qbism-urgleichung.svg)

図はqubitで、地上の測定を $z$ 基底の測定にしたもの。
空の測定を実際に行うと、途中の状態が4つの $\Pi_i$ のどれかに潰れる → 地上の確率は $1/3$ から $2/3$ の範囲に押し込められる。
行わなければ $0$ から $1$ まで動く。

<Details title="コード: Urgleichungの数値確認">
  記事の図を作るscriptの自己検査。$d=2$ と $d=3$ のSICで、Urgleichungの右辺と $\mathrm{Tr}(\rho D_j)$ がランダムな状態について一致することを確認済み。

```python
def sic_probabilities(rho, pis):
    """SIC 測定の結果分布 p(i) = Tr(ρ Π_i) / d。"""
    d = rho.shape[0]
    return np.real(np.einsum("ab,iba->i", rho, pis)) / d


def conditional(pis, effects):
    """r(j|i) = Tr(Π_i D_j): 空の結果 i のあとの状態 Π_i で地上の測定をしたときの分布。"""
    return np.real(np.einsum("iab,jba->ij", pis, effects))


def urgleichung(p, r):
    """Born 則を SIC で書き直したもの: q(j) = (d+1) Σ_i p(i) r(j|i) - 1。"""
    d = int(np.sqrt(len(p)))
    return (d + 1) * p @ r - 1


for pis in (sic_qubit(), sic_qutrit()):
    d = pis.shape[1]
    effects = np.array([np.outer(e, e) for e in np.eye(d)])
    r = conditional(pis, effects)
    for _ in range(20):
        rho = random_state(d, rng)
        born = np.real(np.einsum("ab,jba->j", rho, effects))
        assert np.allclose(urgleichung(sic_probabilities(rho, pis), r), born)
```

### Born則は規範である

Urgleichungの読み方が、QBismの主張の中身。

古典確率論でも、全確率の法則 $q(j)=\sum_i p(i)\,r(j|i)$ が整合性として要求されるのは、途中の測定 $i$ を実際に行う場合だけ
→ 行わない測定について「行ったとしたら」の確率をどう結びつけるかは、確率論の公理は何も言わない
→ 「行わない場合も同じ式が成り立つ」は、整合性から出る帰結ではなく追加の仮定

量子力学はこの隙間をUrgleichungで埋める。
**空の測定を行う場合の信念 $p(i),r(j|i)$ と、行わない場合の信念 $q(j)$ の間に、整合性として満たすべき関係**を1つ付け加える。
それがBorn則であり、「世界がこの確率で結果を出す」という法則ではなく、「agentの信念がこう結ばれていなければ一貫していない」という規範。

係数が $d+1$ と $-1$ である (全確率の法則と少しだけ違う) ことが、世界の側にある客観的な事実だとQBismは考える。
量子状態は主観的だが、Born則の形は主観的ではない。
量子力学は世界の記述ではなく**世界と付き合うためのユーザーマニュアル**で、マニュアルの内容は世界の性質を反映している。

$d^2$ 個の確率の組のうち量子状態として許されるものがどの形になるかを、Urgleichungだけから導き直すのがQBismの「量子力学の再構成」の目標。
まだ完成していない。

## 批判と応答

| 批判                                                     | QBismの応答                                                                                                   |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 唯我論ではないか                                         | 世界の実在は否定していない。測定結果は制御できず、世界はagentを驚かせる。主観的なのは状態であって世界ではない |
| 科学の客観性が失われる                                   | Born則の形 (Urgleichung) と状態空間の形はagentによらない。そこが世界についての客観的な主張                    |
| 測定問題を「解いた」のではなく「問わないことにした」だけ | その通り。収縮が物理過程だという前提のほうが根拠を欠く、という立場                                            |
| 結果が「経験」なら、物理学は意識の理論になる             | 経験は意識の理論を要求しない。agentは人間に限らず、賭けの態度を持つものなら何でもよい                         |
| PBR定理が $\psi$-epistemicな解釈を否定した               | PBR定理は「状態の背後に実在するontic stateがある」ことを仮定している。QBismはその仮定を取らないので対象外     |

## 他の解釈との比較

| 解釈           | 量子状態の実在性       | 収縮         | 非局所性      | 観測者                |
| -------------- | ---------------------- | ------------ | ------------- | --------------------- |
| コペンハーゲン | 曖昧 (計算の道具)      | ある (物理?) | 曖昧          | 古典的な測定装置      |
| 多世界         | 実在 (宇宙の波動関数)  | ない (分岐)  | ない          | 不要                  |
| Bohm           | 実在 (粒子を導く場)    | ない         | ある (明示的) | 不要                  |
| 関係論的       | 系の間の関係           | 関係の更新   | ない          | 任意の物理系          |
| QBism          | 信念 ($\psi$-doxastic) | 信念の更新   | ない          | 賭けの態度を持つagent |

QBismに近いのは関係論的解釈 (RQM) で、どちらも「状態は系そのものの性質ではない」とする。
違いは、RQMが状態を任意の2つの物理系の関係とするのに対し、QBismはそれをagentの信念に限る点。
RQMにはagentも信念も出てこない。
